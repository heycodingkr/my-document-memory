# PRIV: 로컬 우선, 최소 전송, 동의, 개인 정보, 삭제

상태: 설계 초안(문서 우선, 구현 없음). WAM `privacy.md`의 동의·철회·보관·계정 삭제 모델을 승계하되, **문서는 본질적으로 개인 정보를 담는다**는 전제를 추가했다.
영역 / 테스트 ID 접두사: `PRIV` (케이스: [`../test/functional-tests.md`](../test/functional-tests.md))
기반: [`core.md`](core.md), [`memory.md`](memory.md) 7절, [`library.md`](library.md), [`sharing.md`](sharing.md), 시나리오 [`../test/security-scenarios.md`](../test/security-scenarios.md)

## 1. 원칙

1. **로컬 우선, 기본 비공개**: 새 메모리는 비공개이고 로컬 모드에서는 네트워크 요청이 없다.
2. **자동 경로는 최소 전송**: recall은 canonical URL pattern, 양식 필드, 어휘 안의 키워드, kind·scope·limit만 보낸다.
3. **사용자가 시작한 경로는 보이게**: search 질의·웹 검색 질의·가져오기 URL은 사용자가 지정해 외부로 나가며, 나간다는 사실을 `status`·가이드·`remote: true`로 표시한다.
4. **공유는 명시적**: 게시마다 동의가 필요하고 철회할 수 있다. 계정의 허용 스위치는 동의가 아니다.
5. **출처가 사람 이름보다 중요**: 공개 데이터에 이메일·내부 ID·원본 파일·능력 URL을 넣지 않는다.

## 2. 저장·전송·공개 매트릭스

| 데이터 | 로컬 저장 | 서버 전송 | 공개 |
|---|---|---|---|
| 원본 파일 | `originals/<sha256>`(0600) | 서버 모드의 비공개 객체 저장소(소유자만) | 안 함 |
| L0·L1·L2 | 라이브러리 | 계정 라이브러리 | 게시한 버전만 |
| recall 요청 | — | 허용 필드만([`recall.md`](recall.md) 2절) | — |
| search 질의 | — | `team`·`public` 범위일 때 텍스트 전송, 로그에는 해시 | — |
| 가져오기·미리보기 URL | 출처(쿼리 없는 canonical) | 대상 사이트로 직접 | — |
| 웹 검색 질의 | — | 검색 provider로 | — |
| 텔레메트리 | 기본 off | 별도 동의, 내용 없음 | — |

원 URL 문자열, 쿼리, fragment, 능력 URL의 ID, 프롬프트, `task_hint`, 페이지 본문은 서버 요청·로그·진단·캐시·텔레메트리에 남기지 않는다([`core.md`](core.md) 4절).

## 3. 비밀값과 개인 정보

- **비밀값**(API 키 형태, JWT, Bearer, 개인 키 블록 등)은 저장·검색·게시 전체를 원자적으로 거부한다(`secret_detected`). 값과 위치는 응답에 없다.
- **개인 정보 후보**(이메일, 전화번호, 주민·여권·운전면허·카드·계좌 번호 형태, 지역별 주소 패턴)는 휴리스틱으로 감지한다. template은 슬롯으로 치환하고, reference는 보존하되 `contains_personal_data`를 표시하고 비공개로 유지한다. **게시는 막는다.**
- **탐지 한계를 숨기지 않는다**: 이름, 자유 서술 주소, 사진·이미지 속 정보는 놓칠 수 있다. 게시 확인 화면과 CLI 출력은 "자동 탐지는 완전하지 않으며 게시 책임은 소유자에게 있다"는 고지를 보여준다(`PRIV-06`).
- 합성 테스트 데이터만 쓴다. 실제 개인 문서·계정·키를 fixture에 넣지 않는다.

## 4. 동의

- **공유 동의** `share-v1`: 게시마다 `consent=true`와 `consent_version`을 확인하고, 서버는 `consent_version`, 시각, 대상(`memory_id`·`version`·`visibility`·`license`)을 기록한다. 동의가 없으면 서버 요청과 쓰기가 0건이다.
- **철회**: `visibility=private`(게시 취소)은 즉시 공개 조회에서 제외하고 대기 중인 검수 항목을 취소한다. 이미 만든 복사본은 복사 시점에 허용된 라이선스로 남는다는 점을 게시 확인 화면에 알린다.
- **텔레메트리 동의는 공유 동의와 별개**다. 하나를 바꿔도 다른 것이 바뀌지 않는다.

## 5. 보관과 삭제

| 대상 | 보관 |
|---|---|
| 웹 preview | 15분, 이후 삭제 |
| 거절·취소된 게시 요청의 검수 payload | 7일 후 삭제, 사유 코드와 최소 감사 사실만 유지 |
| receipt | 30일 |
| 계정 연결 사용량 집계 | 90일(제안, 배포별 개인정보 정책과 조정 필요), 계정 삭제 시 제거 |
| 요청 원문·원본 IP·URL·질의 텍스트 | 보관하지 않는다 |

- **삭제**(`dmem delete`, 웹): 모든 버전의 내용·색인·보존 원본·캐시 항목을 지운다. 삭제 후 센티널이 어떤 저장소에도 없어야 한다(`PRIV-08`).
- **계정 삭제**: web session, CSRF, `manage:account`, `confirmation=DELETE`가 필요하다. 세션·device·credential을 해지하고 비공개 라이브러리를 삭제한다. 공개·팀 게시물은 사용자가 **삭제** 또는 **작성자 정보 제거 후 유지**를 선택한다(기본은 삭제). 이미 만들어진 타인의 복사본은 남는다. 점수 원장은 금액·버전 관계를 유지하고 사용자 연결만 비식별화한다.
- **운영자 조치(takedown)**: 법적·보안 사유로 공개 조회에서 즉시 숨기고 사유를 최소 감사 메타데이터로 남긴다([`sharing.md`](sharing.md) 3절).

## 6. 공개 데이터

`author_handle`은 사용자가 고른 공개 핸들이다. 리더보드·핸들 공개는 opt-in이고 opt-out은 즉시 반영된다. 이메일, 계정 ID, 기기 ID, receipt ID, 개별 소비자 정체, `source_ref`는 공개하지 않는다([`profile.md`](profile.md), [`score.md`](score.md)).
