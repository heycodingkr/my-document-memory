## 1. 목적과 경계

내 페이지는 현재 계정의 개인 라이브러리, 공개 게시물, 복사 현황, 연결 기기, 게시 동의 기록을 한 곳에서 확인한다. 계정과 세션은 `accounts-community-v1.md`를 따른다. 모든 개인 조회와 변경은 세션의 계정 소유자를 기준으로 한다.

## 2. 내 라이브러리

라이브러리는 `template`·`reference`·`style_rule` kind별 필터, 제목, 현재 정수 `version`, 공개 범위를 보여준다. 각 항목에서 과거 버전을 번호 내림차순으로 확인하고 버전별 시각과 상태를 구분한다.

삭제는 `library.md`의 확인 규칙을 따른다. 모든 버전의 내용·색인·보존 원본을 지우고, 공개·팀 항목은 비공개 전환한다. 다른 사용자가 이미 만든 복사본은 보존된다. UI는 확인 전 삭제하지 않고 삭제 뒤 같은 ID를 찾을 수 없음을 표시한다.

내보내기는 `library.md`와 `formats.md`의 형식·안전 규칙을 따른다. 웹 화면에서의 내보내기 연결은 **제안**이다. 현재 계약의 `dmem export`는 CLI 전용이므로 웹 내보내기를 구현 완료 기능처럼 표현하지 않는다.

## 3. 내가 게시한 항목과 복사

공개 게시물에는 공유 계약의 `author_handle`·라이선스·게시 버전을 표시한다. 복사 현황은 공개 집계 또는 본인 복사본 목록으로 보여주며, 개별 복사자의 계정·이메일·기기 식별자를 노출하지 않는다.

내 복사본은 `derived_from`의 원본 ID·버전·최초 작성자 핸들·라이선스를 표시한다. 원본 takedown 뒤에는 기존 계약의 `origin_taken_down` 경고를 보여주고 재게시 가능 상태로 표시하지 않는다.

## 4. 연결된 기기

기기 목록은 `dmem link` 계정 연결 중 본인 소유만 표시하고, 기기 라벨, 연결 상태, 만료 시각, 허용 scope를 보여준다. 토큰·device secret·user code는 렌더링하거나 복사하지 않는다. `manage:account` 권한으로 선택한 연결만 해지하며 성공 확인 전에는 해지 완료로 표시하지 않는다.

## 5. 게시 동의 기록

`share-v1`은 계정 전체 설정이 아니라 각 게시 요청의 명시적 동의다. 기록 화면은 본인 게시마다 `consent_version`, 시각, 대상 `memory_id`·`version`·`visibility`·`license`를 보여준다. 조회는 동의를 만들거나 바꾸지 않는다. 프로필 공개 설정과 공유 동의는 별개다.

## 6. 개인정보와 오류

다른 계정의 데이터·존재 여부는 응답으로 구별하지 않는다. 계정 전환과 세션 만료 때 이전 계정의 목록·캐시를 먼저 비운다. 이메일, 내부 계정 ID, 원본 URL의 query/fragment, 비밀 credential, 복사자 신원은 목록·내보내기 진단에 추가하지 않는다.
