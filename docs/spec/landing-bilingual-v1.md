# 영문 기본 랜딩과 한국어 언어 전환

상태: 구현 완료, 운영 배포 확인 (2026-11-09). 영역 / 테스트 ID 접두사: `LANG`. 기반: 2026-11-09에 확인한 `web/src/lib/Landing.svelte`, `AgentSetup.svelte`, `WorkflowDemo.svelte`, `DocumentPreview.svelte`.

## 목표와 범위

랜딩은 영어를 기본 언어로 유지하고, 사용자가 직접 한국어로 바꿀 수 있어야 한다. 전환은 랜딩의 본문, 데모, 예시 문서, 연결 안내, 버튼, 상태 메시지와 접근성 레이블에 적용한다. 사용자가 고른 언어는 같은 브라우저의 다음 방문에도 유지한다. 이름과 서비스명, CLI 명령, 코드 설정 값은 번역하지 않는다.

영어 브라우저 로캘을 추측해 언어를 바꾸지 않는다. 로그인 후 앱의 작업공간 번역은 범위에 포함하지 않는다. 계정·API·저장 구조는 변경하지 않는다.

## 의존 순서와 원자 목표

| 순서 / 경로 | 결과 | 독립 부모 확인 | 의존 |
|---|---|---|---|
| 1 / 인라인 | `LANG-01` 언어 계약과 명세·입력·기대 결과 | 변경 전 현재 영어 화면, 중첩 랜딩 컴포넌트, 브라우저 테스트와 배포 경로를 직접 확인 | 없음 |
| 2 / 인라인 | `LANG-02` 기본 영어, 접근 가능한 전환 버튼, `html lang`·제목·설명 메타데이터 갱신, 선택 언어 저장 | 새 브라우저에서 한국어 로캘에도 영어 기본값, 전환 후 페이지 언어와 저장값을 직접 확인 | 1 |
| 3 / 인라인 | `LANG-03` 랜딩 및 포함된 예시·데모·에이전트 연결 안내의 한국어 문구 | 영어·한국어 각 화면과 동적 요청·복사 상태를 소스와 브라우저에서 대조 | 1, 2 |
| 4 / 인라인 | `LANG-04` 화면 폭과 왕복 전환 테스트, 검토된 배포 산출물 | 부모가 테스트·빌드·전체 diff를 직접 실행·검토하고 운영 도메인의 실제 응답을 확인 | 2, 3 |

이 작업은 한 화면의 문구와 언어 상태를 함께 설계해야 하므로 별도 위임 없이 인라인으로 수행한다. 테스트 ID와 고정 입력·기대 결과는 구현보다 먼저 정한다.

## 요구 사항

| ID | 요구 사항 | 관련 테스트 |
|---|---|---|
| F-LANG-01 | 저장된 선택이 없는 방문은 브라우저 로캘과 무관하게 영어로 열리고 영어 제목·설명과 `lang="en"`을 제공한다. | `LANG-01` |
| F-LANG-02 | 헤더에 키보드·스크린 리더로 사용할 수 있는 영어/한국어 전환 버튼을 둔다. 전환 시 표시 문구와 `html lang`, 문서 제목, 설명 메타데이터를 함께 갱신한다. | `LANG-02`, `LANG-03` |
| F-LANG-03 | 한국어 선택은 랜딩의 모든 일반 문구와 접근성 이름, 예시 요청, 데모, 예시 문서, 연결 안내에 적용한다. 승인된 변화 선언 카피의 의미는 두 언어에 유지하고, 외부 링크·명령·설정 값은 보존한다. [카피 기준](landing-ai-writing-v1.md)을 함께 따른다. | `LANG-02` |
| F-LANG-04 | 선택한 언어는 `localStorage`에 저장하며, 새로고침 뒤에도 다시 적용한다. 전환은 영어에서 한국어, 한국어에서 영어 양방향이어야 한다. | `LANG-03` |
| F-LANG-05 | 영어와 한국어에서 320px 화면 폭에 언어 버튼과 탐색을 사용할 수 있고 수평 넘침이 없다. | `LANG-04` |
| F-LANG-06 | 한국어 연결 안내의 복사 버튼은 한국어 상태 문구를 표시하고, CLI 명령은 각 줄을 실제 개행으로 클립보드에 복사한다. | `LANG-05` |

## 테스트 입력과 기대 결과

| ID | 입력 / 동작 | 기대 결과 |
|---|---|---|
| LANG-01 | 새 브라우저 컨텍스트, `locale=ko-KR`, 저장값 없음으로 `/` 방문 | `html lang="en"`, 영어 제목 `My Document Memory — Let AI do the writing.`과 `The era of writing documents yourself is ending.` 히어로, 한국어 자동 전환 없음, 접근 가능한 `Switch to Korean` 버튼 |
| LANG-02 | `Switch to Korean`을 누른다. 히어로·탐색·예시·데모·연결 안내를 확인한다. | `html lang="ko"`; 제목은 `My Document Memory — 문서 작성은 AI에게.`; 히어로 `문서를 사람이 쓰던 시대는 끝나갑니다.`; `소개`, `주간 제품 보고서`, 한국어 Docs 작업 요청, `한 번 요청하고, 세 곳에서 결과를 확인하세요.`, `에이전트를 연결하고 문서 메모리를 이어 쓰세요.`가 보인다. 한국어 접근성 이름과 메타 설명도 제공한다. |
| LANG-03 | 한국어 전환, 새로고침, 영어로 되돌리기, 다시 로드 | 저장 키 `dmem.landing-locale`에 `ko`가 남고 다시 로드해도 한국어다. `영어로 변경` 후 `en`이 저장되고 `lang="en"` 및 기존 영어 문구로 돌아온다. |
| LANG-04 | 영어와 한국어에서 각각 320px 화면 폭으로 전환 버튼·탐색 확인 | 버튼이 보이고 조작 가능하며 `documentElement.scrollWidth <= innerWidth`다. |
| LANG-05 | 한국어로 바꾼 뒤 연결 방법에서 `CLI`를 선택하고 `설정 명령 복사` 실행 | 한국어 완료 상태가 표시되고 클립보드에 7개 CLI 명령이 정확한 순서와 실제 줄바꿈으로 담긴다. |

## 완료 조건

명세의 브라우저 케이스가 통과하고 `pnpm --dir web check`, `pnpm --dir web build`가 성공해야 한다. 부모가 관련 소스와 전체 미커밋 diff를 직접 검토한 다음, 현재 운영 릴리스·헬스 엔드포인트를 다시 확인하고 정적 산출물만 반영하는 새 릴리스로 배포한다. 계정 데이터와 현재 운영 설정은 유지한다.
