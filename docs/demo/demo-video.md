# My Document Memory — 데모데이 영상 구성안

상태: v1 · 2026-11-09 · 기준 문서: [제품 설계 v0.3](../spec/overview.md)  
렌더 방법과 파일 구조: [`demo/video/README.md`](../../demo/video/README.md)

이 영상은 **컨셉 영상**이다. 제품은 아직 설계 단계이고(저장소에는 설계 문서뿐이다), 영상은 설계 문서가 정한 흐름을 그린다. 녹화처럼 보이는 목업으로 "동작한다"고 말하지 않는다. 모든 제품 장면에 `CONCEPT · SAMPLE DATA` 배지를 둔다.

## 한눈에

| 항목 | 내용 |
|---|---|
| 길이 | 2:42(162초), 1920×1080, 30fps, H.264 |
| 언어 | **영어가 기본**이다(`--lang`을 생략하면 영어, 주 산출물은 `mdm-demo-day.en.mp4`). 한국어판은 같은 스테이지에서 `--lang ko`로 렌더한다. 자막은 화면에 굽는다 |
| 음성 | 첫 렌더는 **무음 + 굽힌 자막**. 내레이션 문구는 `script.json`에 같이 있고, 음성은 별도 단계(승인 후)에서 입힌다 |
| 한 줄 메시지 | *5천 년 동안 사람이 만들어 온 문서. 이제 문서가 기억합니다.* |
| 제품 한 줄 | 내 양식·참고자료·작성 규칙을 따로 기억해 두고, 문서와 발표 자료를 양식대로 만든다 |
| 브랜드 표기 | Google Docs·Google Slides·Notion은 **글자로만** 쓴다. 로고를 쓰지 않는다 |

## 이야기

1. **오래된 일 (0:00–0:38).** 인류는 5천 년 넘게 문서를 만들어 왔다. 도구는 점토판에서 Google Docs까지 바뀌었지만 문서를 쓰는 손은 늘 사람이었다. 지금도 문서는 "지난번 파일 찾기"에서 시작하고, 어떤 틀로·어떤 사실로·어떤 말투로 쓸지는 사람 머릿속과 옛 파일에만 있다.
2. **기억을 주다 (0:38–1:36).** My Document Memory는 양식·참고자료·작성 규칙을 따로 기억한다. 내 양식을 저장하고, 다른 사람이 공유한 양식은 작성자·버전·라이선스와 함께 복사해 쓴다.
3. **만들다 (1:36–2:32).** 양식과 참고자료를 고르면 양식대로 초안이 나오고, 근거 문장은 출처로 연결되며, 없는 값은 `확인 필요`로 남는다. 발표 자료는 목차를 먼저 승인받는다. 다음 단계로 Google Docs·Slides·Notion 직접 연결이 있다.
4. **닫다 (2:32–2:42).** 5천 년의 문서, 이제 문서가 기억한다.

## 제작 규칙

- 배지: 씬 1 `HISTORY · DATES APPROXIMATE`, 씬 2 `ILLUSTRATION`, 씬 3–8 `CONCEPT · SAMPLE DATA`. 씬 9에는 한 줄 상태 문구와 상표 문구를 둔다.
- 한 자막은 한 줄. 내용은 y=915 아래로 내려오지 않는다(자막 영역과 겹치지 않는다).
- 이 영상의 근거 문서는 [`overview.md`](../spec/overview.md) v0.3(2026-11-09)과 `template-library.md`다. 설계가 바뀌면(특히 §1·§6의 편집기 범위, Google Docs·Slides·Notion 연결 시점) 클레임 원장 P1–P12를 다시 대조한다.
- 폰트는 OFL(Manrope, DM Sans, DM Mono)을 저장소에 둔다. 한글 글리프는 macOS 시스템 글꼴(Apple SD Gothic Neo)이 채운다. 다른 기계에서 렌더하면 한글 글자 모양이 달라질 수 있다.
- 음성 API 키는 화면·로그·저장소에 두지 않는다. `ELEVENLABS_API_KEY` 또는 `~/.config/mdm-demo/elevenlabs.key`만 읽는다.
- 스테이지는 시간의 순수 함수(`window.__render(t)`)이므로 렌더 결과는 기계 속도에 의존하지 않는다.

- **움직임.** 정지 화면과 프레임으로 확인했다. 영상을 처음부터 끝까지 재생해 본 것은 아니므로 타이밍의 느낌과 장면 전환은 사람이 한 번 봐야 한다.
- **음성.** `make-voice.py`는 `--dry-run`과 "한국어 목소리 미선택 시 거부"만 확인했다. ElevenLabs는 호출하지 않았다.
- **overlay 합성(실제 녹화 끼우기).** 이 저장소에서는 실행해 보지 않았다.
- **다른 기계.** 한글 글리프는 macOS 시스템 글꼴이 채운다.

## 원자 목표와 의존 순서

1. **G0 — 구성안 고정.** 이 문서(장면표, 클레임 원장, V-01~09). 완료.
2. **G1 — 렌더 route.** `script.json` → `stage.html`(시간의 순수 함수) → 프레임 → mp4·srt·poster. 빈 장면으로도 V-01·V-04·V-05·V-07이 통과해야 다음으로 간다.
3. **G2 — 장면 output.** 씬 1–9를 한 덩어리씩 만들고 V-03(정지 화면 확인)과 V-02(lint)를 통과시킨다. 글과 숫자는 클레임 원장에서만 가져온다.
4. **G3 — 전체 렌더.** 영어판(기본)과 한국어판을 렌더한다.
5. **G4 — 독립 확인.** 부모 작업자가 V-01~09를 직접 다시 실행하고, 렌더된 mp4에서 프레임을 뽑아 눈으로 확인한다.
6. **G5 — 음성(승인 후).** `make-voice.py`로 내레이션을 입힌다. 외부 서비스에 문구를 보내고 크레딧을 쓰므로 사용자 승인 뒤에 한다. 한국어 목소리는 직접 들어 보고 고른다.

## 열린 결정

- 어느 데모데이인지(길이 제한). 영어를 기본으로 하고 한국어판도 만들어 두었다.
- 영상 끝의 주소·행동 유도 문구(URL이 정해지면 `script.json`의 마지막 beat와 씬 9에 추가).
- 씬 9의 상태 문구("컨셉 영상 · 예시 데이터 · 제품은 설계 단계")를 유지할지. 제품이 동작하면 녹화로 바꾸고 문구를 고친다.
- 씬 8의 "다음 단계"를 영상에 남길지. 설계 v0.3은 Google Docs·Slides·Notion 직접 생성을 후속 단계로 둔다. 첫 버전 범위가 바뀌면 이 영상도 같이 고친다.
- 씬 5·6의 공유 양식 이름은 설계의 시드 양식 목록([`template-library.md`](../spec/template-library.md): 일일 업무일지 DOC-01, 주간 업무보고 DOC-02, 회의록 DOC-03, 견적서 DOC-07, 사업 제안서 DOC-08, 스타트업 피치덱 SLIDE-01)을 따른다. 그 목록이 바뀌면 이름도 같이 고친다. 사용자 자신의 양식 "분기 보고서"는 예시다.
