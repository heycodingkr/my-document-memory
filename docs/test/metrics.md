## 1. 제품 정확성과 하네스 신뢰성

| 지표 | 합격 기준 | 근거 / 케이스 |
|---|---|---|
| 메모리 분리 | 타 소유자 비공개 데이터 노출 0건; 없는 ID와 같은 응답 | SHR-16, RCL-13, 실제 계정·recall 소유자 테스트 |
| URL·국가·provider | 고정 골든 입력의 canonical·양식·순위·경고 일치 100% | CORE-01~24, FORM-01~16, RCL-01~20 |
| 복사·출처·버전 | 원본 해시/수정 시각 불변, 새 사본 비공개, 원본 버전·작성자·라이선스 유지 | SHR-11~12, SHR-20~21, VER-01~06 |
| 권리·웹 가져오기 | 미확인 라이선스의 prose 복사 0건; 사설 주소 요청 0건; 숨김·주입 문구 재사용 0건 | MEM-14~15, IMP-05~11, SEC-E01~E10 |
| 센티널 | 정의된 말뭉치의 원문·JSON·percent·base64·hex 변형을 8개 sink에서 검사해 유출 0건 | HARN-04, HARN-14, SEC-A04 |
| 문서·코드·포팅 추적 | 정의되지 않은 인용 0건, 필수 케이스 무사유 누락 0건, WAM source 무처분 0건 | HARN-10~12, HARN-17 |
| 결함 민감도 | 깨끗한 더블은 지정 케이스 전부 통과; 변이 18개 각각에서 지정 케이스 전부 실패 | HARN-02 |
| 재현성·정리 | 같은 입력 반복 판정 동일, 테스트 자원 잔존·사용자 탭 변경 0건 | HARN-05~09, HARN-13~16 |

단위 테스트 개수나 코드 커버리지는 보고 지표다. 더블의 변이 검출률은 실제 Rust 제품의 mutation score로 바꾸지 않는다. 계정·기여 검수처럼 구현 계약이 다른 기능은 해당 제품 테스트의 별도 케이스와 결과를 인용한다.

## 3. 문서 작업 A/B 실험

조건은 T(메모리 없음), M(수동 recall), I(호스트 자동 recall)다. 아직 구현되지 않은 I 조건은 미실행으로 남긴다. 동일 모델·effort·도구 버전·요청·양식·출처·초기 상태에서 비교하며 조건 순서를 교차한다. 새 일회용 라이브러리와 세션 소유 Arise 탭을 사용한다.

태스크는 한국어 문서, 영문 문서, 일본어 국가 변형, Slides deck, 공개 양식 복사, 웹 구조 가져오기를 포함한다. 합격 판정은 원문·문단·섹션·슬라이드 순서·내보낸 파일·저장된 버전·출처를 독립 oracle로 확인한다. 대기·실패·무효·수동 개입도 전부 기록한다.

| 지표 | 정의 | 속도·절감 주장 기준 |
|---|---|---|
| 완료 시간 | 첫 도구 호출부터 독립적으로 저장·재조회/내보내기 확인까지; 제출 시점도 별도 기록 | 조건·태스크당 n≥5, 중앙값 ≥20% 감소와 95% bootstrap 차이 CI가 0 미포함 |
| 도구 호출 | 외부 round trip 수, 재시도·복구 포함 | 같은 조건, 중앙값 ≥20% 감소와 CI가 0 미포함 |
| 성공률·품질 | 누락 섹션·잘못된 값·출처 누락·원본 변형도 실패 | M/I가 T보다 성공 횟수가 낮으면 이득 주장 금지 |
| 토큰 | 힌트·검색·초안·검증의 전체 입력/출력 | 순증≤0일 때만 토큰 절감. 증가하면 그대로 보고 |
| 비용·대기 | 실제 청구 또는 API 사용량, 생성/네트워크 대기 분리 | 청구를 측정하지 않으면 비용 절감 주장 없음 |

n=3~4는 예비, n<3 또는 통제 불가는 관찰로만 쓴다. CI는 10,000회 bootstrap, 이상치 제거 없이 전체 run을 기록한다. 무효 비율 20% 초과면 해당 스위트 결과를 무효로 남긴다. 비교 전 [`prereg/_template.md`](prereg/_template.md)로 가설·주 지표·판정·환경을 고정하고 Git revision이나 원본 해시를 증거에 남긴다.

## 4. 출처와 변경 이력

WAM의 과거 웹 작업 수치는 WAM의 측정이다. DMEM 제품의 측정으로 승계하지 않는다. 원본 벤치마크·배포 실행 기록은 포팅 목록에서 제외 이유를 남기며 실험 설계·검증 규칙만 적응한다.

| 날짜 | 변경 | 이유 |
|---|---|---|
| 2026-11-09 | WAM 수치·호스트 가정과 DMEM 계약 예산 분리, 문서 oracle·포팅 게이트 추가 | 제품 없는 초기 기록과 현재 Rust 부분집합, 더블 검증을 구분 |
