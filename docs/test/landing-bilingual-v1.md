상태: 운영 검증 PASS (2026-11-09). 요구 사항: [`../spec/landing-bilingual-v1.md`](../spec/landing-bilingual-v1.md). 테스트 ID: `LANG-01~05`.

모든 케이스는 새 Playwright 컨텍스트를 사용하고, 브라우저 로캘은 `ko-KR`, 저장소는 비운다. 제품명·서비스명·CLI 구문은 고유명사/코드로 간주한다. 화면 문구는 각 기대 결과와 실제 표시 문자열을 비교한다.

| ID | 입력 / 동작 | 기대 결과 |
|---|---|---|
| LANG-01 | `locale=ko-KR`, `localStorage` 비어 있음, `/` 열기 | `html lang=en`; 영어 제목·히어로·탐색; `Switch to Korean` 버튼. 로캘만으로 한국어로 바뀌지 않는다. |
| LANG-02 | 언어 버튼을 누르고 페이지의 히어로, 예시, 데모, 연결 안내를 확인 | `lang=ko`; 제목 `My Document Memory — 문서 작성은 AI에게.`; 히어로, 예시 요청, 데모, 연결 안내가 한국어이며 한국어 메타 설명과 접근성 레이블이 있다. |
| LANG-03 | 한국어 선택 후 reload, `영어로 변경` 클릭 후 reload | 한국어 선택은 `dmem.landing-locale=ko`로 유지된다. 영어 전환은 `dmem.landing-locale=en`으로 저장되고 영어 제목/문구와 `lang=en`을 복원한다. |
| LANG-04 | 각 언어에서 뷰포트를 320×844로 설정하고 언어 버튼 및 메뉴 사용 | 버튼과 탐색이 화면 안에서 보이고 조작 가능하다. 수평 넘침이 없다. |
