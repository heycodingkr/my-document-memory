# 문서 작업 실험 사전 등록

상태: 실행 전 템플릿. 파일을 복사해 값을 채우고 실행 전에 Git revision 또는 SHA-256으로 고정한다. 합격 기준은 [`../metrics.md`](../metrics.md)를 따른다.

- 실험 ID / 등록 시각 / 작성자:
- 검증할 가설 / 주 지표 / 예상 효과:
- 대상: 제품/더블, Git revision·dirty diff hash, binary hash:
- 호스트·Arise·OS·모델·effort·MCP 도구 버전:
- 태스크와 합성 fixture·국가·locale·provider·양식/출처 버전:
- 조건 T/M/I와 조건·태스크당 반복 수:
- 조건 순서(교차/블록 무작위)와 seed:
- 초기 라이브러리·계정·탭·캐시 초기화 방식:
- 독립 oracle(저장·재조회·내보내기·출처·품질 판정):
- 시작·제출·완료 시점, 호출/토큰·비용·대기 수집 방식:
- 성공/실패/무효·수동 개입의 사전 판정 규칙:
- 보안·개인정보·라이선스 및 정리 판정:
- 전체 run 결과·원본 trace·파일·캡처 보관 경로:
- 기준 변경 이력(변경 전/후와 실행 전 고정 시각):

실행 뒤에는 모든 run을 붙인다. 로그 침묵이나 에이전트의 완료 메시지로 성공을 판정하지 않는다.
